The parent `/Users/adrian/CLionProjects/AGENTS.md` applies. Read `README.md`

## Branches

Do all development, including documentation and release preparation, on
`develop` or `hotfix`. If `develop` does not exist yet, create it
from the current `main` before starting work. Use `hotfix` only
for fixes to a released version. Do not develop directly on `main`, and do not
create any other branch names (including feature, task, release or temporary
branches). `main` is for approved integration and releases.

Do not commit, push, merge, tag or publish without explicit session
authorisation.
