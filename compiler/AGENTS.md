# Compiler agent guide

Read the root `AGENTS.md`, this component's README, UPSTREAM.md and
doc/BACKLOG.md before changing the compiler. Maintain one live source tree in
`src/gcc16/`. Make changes there and record them through normal Git history.
Do not edit or apply the frozen `archive/recovery/` series as a development
workflow. Keep generated upstream and build trees outside maintained source.
Preserve inherited notices and qualify affected profiles.
